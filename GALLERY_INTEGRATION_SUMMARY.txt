───────────────────────────────────────────────────────────────────────────────────────────────────
 COMPONENTS CREATED
───────────────────────────────────────────────────────────────────────────────────────────────────

1. src/hooks/useScrollProgress.ts
   └─ Shared scroll progress source of truth
   └─ Ref-based updates (no React re-renders on scroll)
   └─ Functions: getScrollProgress(), useScrollProgress(), subscribeToScrollProgress()

2. src/components/gallery/GalleryScene.tsx
   └─ Main R3F Canvas component
   └─ Camera rig with smooth lerp & bob effect
   └─ Fixed positioning (z-index: 1)
   └─ dpr capped at [1, 2] for performance

3. src/components/gallery/Corridor.tsx
   └─ Static corridor geometry (floor, ceiling, walls, trims)
   └─ Memoized with React.memo()
   └─ Brass accent trims for architectural detail
   └─ Fog effect for depth

4. src/components/gallery/Bay.tsx
   └─ One frame + spotlight per project
   └─ Distance-based lighting (brightens as camera approaches)
   └─ Emissive glow synchronized with spotlight intensity
   └─ Recalculates every useFrame

5. src/pages/GalleryPage.tsx
   └─ Page wrapper for gallery
   └─ Combines GalleryScene + ScrollPanels

6. src/components/gallery/ScrollPanels.tsx
   └─ HTML text overlays (5 projects)
   └─ HUD (progress bar + panel count)
   └─ Motion animations (opacity driven by scroll)
   └─ Scroll cue that fades after scrolling

7. tailwind.config.ts
   └─ Gallery color scheme
   └─ Font families (Space Grotesk, Inter, JetBrains Mono)
   └─ Custom spacing & letter-spacing
